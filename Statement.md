#### \## Problem Statement



* ###### Many students managing their own finances for the first time or people who are not used to manage their expenses struggle to keep track of their spendings and budgets. Manual methods of using paper or notes to write down the data is sometimes inefficient. So this project gives a digital way of storing that data addressing the need for a simple user friendly and persistent expense tracking system.





#### \##Scope of the project 



###### This is a basic expense management project which facilitates simple day to day expense recording with essential details like category, amount, and optional notes. The project also have a visualization option which enables the user to quickly and easily see the category wise spending,

###### The data is saved in a csv file enabling users to retain and review their spending history between sessions without need a database setup. It has command line menu with easy to understand choice based options to use various functions within the program and it is capable to handle basic user input for functionality 



* ##### Future enhancements:

###### Adding more filters and search options to view expenses more specifically 

###### Supporting multiple users with login option

###### Implementing a GUI using tools like Tkinter

###### Adding alerts and notifications for budget management





#### \## Target Users 



###### This project mainly targets students and individuals who are either managing their finances for the very  first time or having problems with it .



#### \## High Level Features



###### Use of CSV files to store data ensuing that data is retained between sessions and can be relooked into 

###### Use of  library such as matplotlib for data visualization which provides a quick and easier way to see the data

###### Simple Command line interface
