# \# Python Expense Tracker





### \##Overview



###### This is a beginner friendly command line Expense Tracker application built using Python. The project enables users to track their daily expenses by recording information such as date, category, amount and optional notes. Users can view the list of their expenses and see a graphical representation of spending by category to better understand their financial habits.





### \## Features



* ###### Add new expense entries with date, amount, category and notes
* ###### View all recorded expenses in a clear table format.
* ###### Save and load expenses from a CSV file ensuring persistent data storage
* ###### Visualize expense distribution across categories with the help of bar charts 
* ###### Simple choice based menu for navigation





### \##Technologies Used 

###### 

* ###### Python 3.13
* ###### Standard Libraries: 'csv' and 'datetime'
* ###### External Library : 'matplotlib'





### \## Installation and Running the Project



###### 1, Clone or download the project files to your local machine



###### 2\. Install Python if not already installed. Download from https://www.python.org/downloads/



###### 3\. Install matplotlib library using command ' pip install matplotlib'



###### 4\. Run the project by executing the python script in a terminal or command prompt: python VITyarthi Project





### \## Instructions for Testing



* ###### On running the program a simple choice based menu will appear 
* ###### Test by adding sample expenses with various categories and amounts 
* ###### View the expenses list to verify if data is being correctly recorded or not 
* ###### Select option to display graph of expenses to check the correctness of the bar graph
* ###### Exit the program to save the data in the csv file and re-run the program to ensure if the previous data was saved correctly or not
